# Hollow Frontier Roblox — staged delivery

## 0.2 / First Light (this package)
First playable Studio foundation: original biome map, scavenging, player-created shelters and machinery, animated native avatars, creatures, three save slots, and first two Meridian clues. Desktop and mobile UI generated in source.

## 0.3 / Shared Frontier
- Invites and cooperative plot permissions (owner approves building, storage, machine operations).
- True expedition instances and shared session objectives.
- Reliable building placement preview, rotation, and collision diagnostics.
- NPC behavior and ground navigation, creature species and environmental responses.
- Main server load testing, save conflict/failure regression, console and phone playtesting.

## 0.4 / Wilderness Cinematic
- Professionally modeled original assets with documented licenses, animations, facial rigs, and LOD.
- Meridian camp NPC, deeper NORA dialogue and scripted camera moments.
- Ambient sound design, environment events, and accessible reduction settings.
- Story chapter II with Ashwood expedition and distinct quests.

## 0.5+ / Full Campaign
- The Meridian Files, network relay system, three story outcomes; no destructive reset after finishing.
- Reconciliation/Silence/Reconstruction conclusion and replayable high-tier expeditions.
- Live operations, in-game tutorials, telemetry, release monitoring and staged Roblox rollout.

## Release gate
Do not mark Roblox public/production-ready until Studio rendering, server validation, data persistence, multi-client safety, moderation/legal review, platform policy compliance, and mobile graphics stability are directly checked.
