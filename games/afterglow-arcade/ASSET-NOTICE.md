# Afterglow Arcade asset attribution note

The bundled README identifies `assets/kenney-arrow.png` as an asset from Kenney's UI Pack and cites https://kenney.nl/assets/ui-pack under CC0. The bundled `assets/KENNEY-LICENSE.txt` identifies "Castle Kit (2.0)" instead. Both files are retained exactly as supplied; this discrepancy should be corrected against the original download before distributing new modified versions. Source for the game and its other assets is the user-provided Afterglow Arcade v1.0.0 package.
